# Segurança e privacidade

## Objetivos

- proteger dados pessoais e de perfil do usuário
- garantir autoria e auditoria de alterações administrativas
- impedir acesso indevido a dados sensíveis

## Medidas esperadas

- autenticação para usuários e administradores
- autorização por roles e escopos de acesso
- criptografia em trânsito e em repouso
- consentimento explícito para coleta e uso de dados
- registro de auditoria para acessos e alterações de regras
- política de retenção e exclusão de dados
- revisão periódica de vieses e regras de recomendação

## Riscos principais

- vazamento de dados pessoais
- uso indevido do histórico profissional do usuário
- recomendação enviesada por critérios ocultos
- autenticação fraca em admin e em integrações externas

## Mitigações

- mínimo necessário de dados
- separação de funções por perfil
- monitoramento de logs e alertas
- revisão de regras por responsável da área de negócio
- testes de segurança e análise de acessos
